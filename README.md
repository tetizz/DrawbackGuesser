# DrawbackGuesser

DrawbackGuesser is an open-source research and training application for
identifying the hidden drawbacks in completed Drawback Chess games.

It combines:

- exact symbolic elimination from an executable drawback rule engine;
- independent Bayesian hypothesis distributions for White and Black;
- leakage-audited neural training and evaluation;
- authenticated browser model artifacts;
- offline completed-PGN analysis with per-ply prediction history.

The neural model can rank only hypotheses that survive exact legality checks.
It can never restore a symbolically eliminated drawback.

## Architecture

This repository owns prediction, model training/evaluation, dataset consumer
validation, and browser inference. Authoritative chess legality and drawback
rules are supplied by the pinned `DrawbackEngine` submodule under `engine/`.
Rule filters are not duplicated here.

```text
engine/                         pinned legality and public-position authority
packages/predictor/             symbolic and Bayesian hypothesis engine
packages/dataset-contract/      strict public-feature/label separation
packages/trace-to-dataset/      trusted Engine-trace derivation boundary
apps/dataset-cli/               streaming private dataset converter
apps/web/                       completed-PGN browser inference
ml/training/                    deterministic PyTorch training and export
ml/evaluation/                  metrics, calibration, promotion, sealed tests
```

## Requirements

- Node.js 22 or newer
- pnpm 11.9.0
- Python 3.11 or 3.12
- CPU or CUDA PyTorch compatible with `ml/requirements.txt`

Clone with the engine dependency:

```bash
git clone --recurse-submodules https://github.com/tetizz/DrawbackGuesser.git
cd DrawbackGuesser
pnpm install --frozen-lockfile
python -m pip install -r ml/requirements.txt
```

If the repository was cloned without submodules:

```bash
git submodule update --init --recursive
```

## Run the browser analyzer

```bash
pnpm --filter @drawbackguesser/web dev
```

Paste a completed PGN to inspect the White and Black drawback distributions,
hard eliminations, parameter guesses, and per-ply prediction timeline. A local,
authenticated model artifact may be loaded to add neural ranking. Evaluator
dependent hypotheses require a uniformly generated and authenticated sidecar.

## Data and model artifacts

Generated corpora, private manifests, checkpoints, browser models, and
completed real-game PGNs are not committed. Training consumes
content-addressed datasets generated by the engine and immediately separates:

- public model features;
- trusted training labels;
- evaluation-only metadata.

Unknown fields and label leakage fail closed. See
`docs/architecture/browser-hybrid-inference.md` for the full trust boundary.

Convert a private Engine trace into contract-checked training rows with:

```bash
pnpm --filter @drawbackguesser/dataset-cli start -- \
  --input ../DrawbackEngine/data/private-traces.ndjson \
  --output ../DrawbackGuesser-private/private-training.ndjson \
  --require-evaluator uniform
```

Convert the replay-verified player-private capturable-king corpus with:

```bash
pnpm --filter @drawbackguesser/dataset-cli start -- \
  --input ../DrawbackEngine-private/player-private-train.ndjson \
  --output ../DrawbackGuesser-private/capturable-train.ndjson \
  --require-authority capturable-king/v1 \
  --require-evaluator none
```

New capturable rows use symbolic feature schema 9 and the Engine's frozen
25-rule audited authority catalog. They include the complete public position
snapshot needed for one-reply king-passant plus a public, exact
`25 rules x 4 fields` opportunity tensor. Secret IDs, parameters, rule state,
legal masks, trigger flags, and results remain label-only fields. The feature
chronology and leakage boundary are defined in
[`docs/architecture/rule-opportunity-features.md`](docs/architecture/rule-opportunity-features.md).

Historical 10-label schema-7 corpora and 25-label schema-8 corpora remain
frozen research artifacts. Legacy and opportunity-aware loaders are explicit;
one schema cannot be silently interpreted as another.

The first 25-label experiment uses a two-stage selection/sealed-test boundary
defined in
[`docs/research/capturable-25-baseline-protocol.md`](docs/research/capturable-25-baseline-protocol.md).
Training and validation publish a frozen checkpoint without accepting a test
path; the separate sealed evaluator rejects overlapping games and writes one
authenticated, no-clobber report.

The schema-9 opportunity residual is evaluated as a matched, same-seed
`public-exact` versus `zero-ablation` experiment on newly generated data. Its
preregistered selection and promotion gates are defined in
[`docs/research/capturable-25-opportunity-ablation-protocol.md`](docs/research/capturable-25-opportunity-ablation-protocol.md).

The input and output contain hidden labels and must remain private. The
example deliberately writes outside the repository; do not place private
NDJSON under the Guesser worktree. The converter derives every model feature
from a label-free public projection,
updates White and Black symbolic distributions independently, then attaches
the active player's pre-move secret state as a training label. It streams
bounded UTF-8 lines, rejects duplicate games or mixed evaluator identities,
uses private file permissions where supported, and never overwrites an
existing dataset. See
`docs/architecture/engine-trace-dataset-bridge.md`.

## Safety

DrawbackGuesser is for offline training and analysis of completed games. It
does not scrape external chess sites or provide covert live competitive
assistance.
