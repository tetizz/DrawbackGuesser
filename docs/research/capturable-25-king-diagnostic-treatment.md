# Capturable 25-label king-diagnostic treatment

## Scope

This experiment tests whether extra public king-capture opportunities improve
the 25-label hybrid guesser without changing the validation or test labels
available to model selection. It is a synthetic self-play experiment, not
evidence about live human accuracy.

The frozen control is the selected v1 checkpoint documented in
`capturable-25-baseline-protocol.md`:

- checkpoint SHA-256:
  `e5f58efe34d13110d4742fe352e064c70e537e2f8536b17dc49aa87886b8738e`;
- validation schema-8 SHA-256:
  `3a2724f753e6f8c07a95d9ea0a7ea7f558b0359dfaa863b9e7facc62e0ae3092`;
- validation games/rows: 625 / 30,736.

The already consumed v1 test is not reused.

## Known corrective follow-up

The concentrated supplement changes the empirical class prior and makes the
diagnostic position correlated with one of five labels. DrawbackEngine now
defines a separate `catalog-balanced-king-diagnostics-v1` profile that applies
the same public scenarios to all 25 labels. That profile is reserved for a
later, separately validated hard-negative experiment and does not change this
frozen treatment or its test decision.
